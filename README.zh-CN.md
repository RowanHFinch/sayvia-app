# Sayvia

[English](README.md)

Sayvia 是原生 macOS 语音输入工具。在任何应用的输入框里按一下 **fn** 开始说话，再按一下结束。Sayvia 会识别你说的话，整理成通顺的文字（去掉口头禅，改正口误，比如「三点，不对，四点」会写成「四点」），然后写在光标处。

Sayvia 用你自己的 API Key，直接请求你选的语音和大模型服务商，中间没有 Sayvia 的服务器。

> **状态：alpha。** 日常可用，但还没有经过 Apple 公证，也没有大范围测试，可能会遇到问题。

## 功能

- 在任何应用的输入框里使用，按 **fn** 或 **⌥⌘Space** 触发。
- 整理时保留原意、数字和语言，去掉口头禅和说错的部分。
- 阿里云百炼支持实时识别：边说边识别，停下后很快出字。其他服务商在停录后整体识别。
- 个人词典收录人名和术语。可以开启自动学习：听写后改正识别错的词，会自动加入词典。
- 历史记录连同音频保存在本机，可以复制、重新整理或导出。
- 界面支持中文和英文，跟随系统语言。

## 系统要求

- macOS 14 或更高版本。
- 一个受支持服务商的 API Key：
  - **阿里云百炼（Model Studio）**：支持北京和新加坡地域，推荐使用，也是目前唯一支持实时识别的服务商。还需要百炼控制台里的 **Workspace ID**。
  - **OpenAI**：Whisper 负责识别，对话模型负责整理。
  - **任意 OpenAI 兼容服务**：分别填写完整的 `…/audio/transcriptions` 和 `…/chat/completions` 地址。

费用由服务商按你账号的实际用量收取。

## 安装

### 下载安装包

1. 从 [Releases](../../releases) 下载 `Sayvia-<版本>.dmg`，把 **Sayvia** 拖进「应用程序」。
2. 打开 Sayvia。因为还没有经过 Apple 公证，第一次打开会被系统拦下：
   - 打开「系统设置 → 隐私与安全性」，往下找到 Sayvia 的提示，点「仍要打开」，再输入密码确认。
   - 或者在终端里运行一次：

     ```bash
     xattr -dr com.apple.quarantine /Applications/Sayvia.app
     ```

正式版本都用同一张固定的自签名证书签名，所以更新后通常不用重新授权（这一点还没在很多台 Mac 上验证过）。

### 从源码构建

需要 Xcode 16 或更高版本（只装 Command Line Tools 会缺少 SwiftUI 宏）。

```bash
git clone https://github.com/RowanHFinch/sayvia-app.git
cd sayvia-app
scripts/build-app.sh
open dist/Sayvia.app
```

`build-app.sh` 会用名为「Sayvia Release Signing」的本地自签名证书签名，钥匙串里没有时会自动创建。设置 `SAYVIA_SIGNING_IDENTITY=-` 可以改用临时签名，但这样每次重新构建后，系统都会要求重新授权。

离线自检（只用临时数据，不联网）：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift run Sayvia --self-test
```

## 首次设置

第一次打开会引导你完成四步：

1. **隐私**：确认会发送哪些内容，并选择历史保留多久。
2. **服务**：选择服务商，粘贴 API Key。百炼还要填写 Workspace ID，也可以直接粘贴专属域名。之后可以在「设置 → 服务」里分别设置识别和整理的服务商；那里的「检查连接」会发一个极短的整理请求，确认 Key 可用。
3. **权限**：
   - **麦克风**：用于录音。
   - **辅助功能**：用于找到当前输入框并写入文字。
   - **输入监控**：让 fn 在所有应用里生效。
4. **试一试**：说一句话。

## 隐私

- 录音、转写、历史和词典都保存在你的 Mac 上，位置是 `~/Library/Application Support/io.github.rowanhfinch.sayvia`。
- API Key 存在 macOS 钥匙串里，每个服务商域名一个。
- 只有在听写、重试或检查连接时，数据才会离开你的 Mac。每次都**直接发给你选的服务商**，内容包括：
  - 音频；
  - 词典里的词；
  - 光标附近的少量文字和窗口标题；
  - 当前窗口里的可见文字，用来帮助认出人名和术语。可以在「设置 → 数据与隐私 → 参考屏幕文字」里关闭。密码框不会读取。
- 开启自动学习后，只会发送改动的部分和前后几个词，用于判断是否加入词典。
- 没有统计、遥测或云同步。在 Sayvia 里删除数据，不会删除服务商那边可能留存的内容，具体请看服务商的数据政策。

## 文字怎么写入

文字准备好时，Sayvia 会写进当时有焦点的输入框：临时借用剪贴板粘贴一次，随后恢复你原来的剪贴板内容。如果剪贴板无法安全借用（比如里面是密码或图片），就改为直接输入文字。

Sayvia 不会重复写入，也不会按「发送」。如果无法确认文字已经写进去，结果会留在历史记录里，你可以手动复制。

## 已知限制

- 还没有经过 Apple 公证，安装方法见[安装](#安装)。
- 实时识别只支持百炼。其他服务商要等停录后才开始识别，出字会稍慢一些。
- 识别和整理的效果取决于服务商和所选模型。
